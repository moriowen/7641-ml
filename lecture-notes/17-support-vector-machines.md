## Prep questions

Answer these before lecture; they're the ones that tend to decide whether the lecture lands.

- [ ] Set up the max-margin primal, then derive the dual with Lagrange multipliers. This is the core derivation of the topic.
- [ ] Which points are support vectors, and what do the KKT complementary-slackness conditions say about them?
- [ ] Soft margin: what does C trade off, and what happens as C goes to 0 or infinity?
- [ ] Hinge loss vs logistic loss — plot both and compare.
